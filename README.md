## 投递建议

1. 先确认毕业时间对应的招聘项目，再选择岗位，避免投错批次。
2. 优先使用岗位直达链接；链接失效时，可在招聘官网搜索职位 ID 或岗位全名。
3. 简历中突出与岗位直接相关的项目：多模态训练、机器人控制、强化学习、数据闭环、嵌入式系统或工程落地经验。
4. 使用内推码不代表录用保证，招聘进度和结果以公司官方通知为准。
5. 联系招聘人员时，建议一次性提供：姓名、学校与学历、毕业时间、目标岗位、简历链接或附件，以及最匹配的 2–3 条经历。
